HOW TO PLAY
Move: Left Stick (Axes 0 & 1) / WASD
Look: Right Stick (Axes 2 & 3) / Trackpad / Pointer Lock / Touch Drag
Jump: A Button / Space / ⤒ Button
Mine: R2 / Right Click / ⛏ Button
Build: L2 / Left Click / ▦ Button
Open/Close Door: Aim at a door and use the Build action
Cycle Hotbar: L1 & R1 / 1-5 keys
Pause / Map Controls: Esc / Start / ⏸ Button
Inventory: E / 🎒 Button

New: Dig for caves & ore, place torches for light, build doors you can open

Multiplayer: Hit Play, create a room, then share the invite link so friends on any Wi-Fi or mobile data can join your world.
